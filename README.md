# Trabajo práctico 01

## Descripción

Este proyecto reúne dos ejercicios de la primera semana del curso de Desarrollo back-end con Node.js.

El archivo `index.js` genera una ficha de un videojuego utilizando datos del videojuego y datos del entorno de ejecución de Node.js. La ficha se muestra en la terminal y también se guarda automáticamente en un archivo de texto.

El archivo `orden-event-loop.js` demuestra el orden de ejecución entre el código principal y una tarea programada mediante `setTimeout`.

Para ejecutar el programa principal:
